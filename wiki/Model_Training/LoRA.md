**LoRA(Low-Rank Adaptation)는 사전학습 가중치를 고정하고, 작은 저랭크 행렬만 학습해 모델을 미세조정하는 방법입니다.** 핵심은 **가중치의 변화량을 적은 파라미터로 표현하는 것**입니다.

**1. 상위 개념**

LoRA는 **PEFT(Parameter-Efficient Fine-Tuning, 파라미터 효율적 미세조정)**의 한 종류입니다.

- **전체 미세조정:** 모델의 모든 가중치를 학습합니다.
- **LoRA:** 기존 가중치는 고정하고, 선택한 가중치에 더할 변화량만 학습합니다.

**2. 해결하려는 문제**

대형 모델 전체를 학습하면 가중치의 gradient와 optimizer 상태를 저장하는 데 많은 메모리가 필요합니다. 태스크마다 모델 전체를 저장하는 비용도 큽니다.

LoRA는 학습 대상과 태스크별 저장량을 줄입니다. 다만 **기본 모델과 중간 활성값의 메모리는 여전히 필요하므로**, 학습 파라미터 감소율만큼 전체 메모리가 줄지는 않습니다.

**3. 핵심 아이디어**

원래 가중치 행렬 $W_0$에 더할 변화량 $\Delta W$를 두 작은 행렬의 곱으로 표현합니다.

$$
\Delta W = \frac{\alpha}{r}BA
$$

여기서 $r$은 저랭크 구조의 크기입니다. $BA$의 rank는 최대 $r$이므로, 학습 가능한 변화량에 제약이 생깁니다.

직관적으로는 **큰 행렬의 각 원소를 독립적으로 바꾸는 대신, 소수의 학습 가능한 변화 패턴을 조합하는 방식**입니다. 태스크 적응에 필요한 변화가 낮은 rank로도 표현될 수 있다는 가설에 기반합니다.

**4. 동작**

1. 적용할 선형 계층에 $A$, $B$를 추가합니다.
2. 입력을 기존 경로 $W_0x$와 LoRA 경로 $BAx$로 계산해 합칩니다.
3. 손실을 역전파해 $A$, $B$를 업데이트합니다. $W_0$는 고정합니다.
4. 학습 후 $A$, $B$만 저장하거나, 변화량을 $W_0$에 합쳐 사용합니다.

원 논문은 $A$를 무작위 값, $B$를 0으로 초기화해 학습 시작 시 변화량이 0이 되도록 합니다. 가중치에 병합하면 추론에서 별도 LoRA 경로를 계산할 필요가 없습니다.

**5. 핵심 수식**

입력 차원이 $k$, 출력 차원이 $d$라면:

$$
W_0 \in \mathbb{R}^{d \times k}, \qquad
A \in \mathbb{R}^{r \times k}, \qquad
B \in \mathbb{R}^{d \times r}
$$

$$
h = W_0x + \frac{\alpha}{r}B(Ax)
$$

- $r$: 변화량의 최대 rank를 정하는 설정
- $\alpha$: LoRA 경로의 크기를 조절하는 설정
- $\alpha/r$: 원래 LoRA의 스케일링 방식

해당 행렬의 학습 파라미터 수는 다음과 같습니다.

$$
N_{\text{full}} = dk, \qquad
N_{\text{LoRA}} = r(k+d)
$$


**6. 예시**

$4096 \times 4096$ 선형 계층 하나에 $r=8$을 적용한다고 가정하면:

| 방식 | 학습 파라미터 수 |
|---|---:|
| 해당 행렬 전체 학습 | $4096^2 = 16,777,216$ |
| LoRA | $8(4096+4096) = 65,536$ |

이 행렬에서는 학습 파라미터가 **256분의 1, 약 0.39%**가 됩니다. 모델 전체의 감소율은 적용하는 계층 수와 종류에 따라 달라집니다.

**7. 관련 개념**

| 개념 | LoRA와의 관계 |
|---|---|
| **PEFT** | LoRA가 속하는 상위 범주 |
| **SFT** | 정답 예시로 학습하는 방식. LoRA를 사용해 SFT를 수행할 수 있음 |
| **QLoRA** | 기본 모델을 4비트로 양자화한 상태에서 LoRA를 학습하는 방법 |
| **Adapter tuning** | 별도 모듈을 추가해 학습하는 다른 PEFT 방식 |

SFT는 **어떤 신호로 학습하는가**, LoRA는 **어떤 파라미터를 학습하는가**에 해당합니다. QLoRA는 여기에 기본 모델의 저장 정밀도를 낮추는 방법을 결합합니다.

**8. Notes**

- **저랭크 제약은 변화량 $\Delta W$에 적용됩니다.** 기본 가중치 $W_0$ 자체가 저랭크라는 뜻은 아닙니다.
- $r$을 키우면 표현 가능한 변화의 범위와 학습 비용이 늘어납니다. 최적값은 태스크와 적용 계층에 따라 검증해야 합니다.
- 현재 계수 실험에서 LoRA는 **계수 절차를 학습시키는 수단**입니다. LoRA 적용만으로 계수 능력이 개선되는지는 별도 평가로 확인해야 합니다.
